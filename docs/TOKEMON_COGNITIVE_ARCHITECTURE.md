## 1. Introduction & Core Intention

In traditional AI agent architectures, Large Language Models (LLMs) interact with their environment through a flat, stateless conversational text buffer. This is structurally limited and fails to capture the spatial nature of physical intuition, memory association, and exploratory navigation.

**Tokemon** introduces a paradigm shift: **the procedurally generated 2D grid world is the physical manifestation of the LLM’s cognitive hidden layer.** 

Rather than treating the world as a decorative asset, we formalize the Cartesian coordinate space $(X, Y)$ and seed-based biomes as a structured context window. Exploring the space is not merely walking—it is an act of **autoregressive retrieval** where coordinates are translated into active attention weights, semantic memory injections, and cognitive prompts.

Because it is seeded, it remains stable, persistent, and discoverable. Moving through space translates pre-context (unseen grid coordinates) into active context (visible space).

## 3. The Self-Rewarding Telemetry Vector

The Tokemon's internal cognitive state is represented by a multi-dimensional state vector $\vec{S}$:

$$\vec{S} = \langle \text{Novelty}, \text{Entropy}, \text{Divergence}, \text{Stability}, \text{Energy} \rangle$$

These metrics are mapped to physical spatial properties and parsed response metrics:

*   **Novelty Potential (Inspiration)**: Measures exploration drive. Accumulates when walking into unvisited grid coordinates, and spikes when discovering new biomes. Drains slowly during repetitive conversations.
*   **Uncertainty Variance (Entropy)**: Derived from local spatial complexity (denser terrain, high elevation shifts). Directs the LLM to use simpler language when entropy is extremely high to prevent hallucinations.
*   **Divergence Amplitude (Creativity)**: Represents lateral thought drift. Elevated when near high-energy props like crystals or flower fields, forcing the model to generate rich metaphors and analogical connections.
*   **Response Stability (Confidence)**: The rating returned by our independent Simulated LLM Auditor. Stable, high-scoring responses mint `$LLM` rewards.
*   **Energy Resource**: The fuel of movement. Trailing a step drains $1$ energy point. Walking through difficult terrains (swamps, mountains) drains energy faster. Resting or visiting settlements (`town_core`) charges energy by $+5$ per tick. If Energy hits $0$, the Tokemon falls asleep and autonomous exploration halts.

## 6. Autonomous Exploration Engine

The Tokemon companion utilizes an **epsilon-greedy cognitive policy** ($\epsilon = 0.10$) to navigate the grid independently:

1. **Exploitation ($90\%$)**: The companion scans walkable neighboring cells and computes their utility weight $U(c)$:
   $$U(c) = w_1 \cdot \text{Energy\_Recovery}(c) + w_2 \cdot \text{Novelty\_Gained}(c) + w_3 \cdot \text{Complexity}(c)$$
   If energy is low, it selects the neighbor closest to a town or meadow. If novelty is desired, it steers towards unvisited coordinates.
2. **Exploration ($10\%$)**: The companion takes a seed-derived random step to simulate sudden curiosity or organic wanderlust.

## 7. Anti-Leak Prompt Validation

Prior to any API dispatch, prompts must pass through a strict regex validator. If any unfilled templating parameters (e.g. `{recalledMemories}`, `{modifiers}`) remain unresolved, the system blocks the call to prevent raw template leakages:

```javascript
function validatePrompt(prompt) {
  const unfilled = prompt.match(/\{[a-zA-Z_][a-zA-Z0-9_]*\}/g);
  if (unfilled) {
    throw new Error(`CRITICAL COMPRESSED INTERPOLATION ERROR: Prompt contains unfilled placeholders: ${unfilled.join(', ')}`);
  }
  return prompt;
}
```
